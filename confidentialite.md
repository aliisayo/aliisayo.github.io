## Données traitées

**Statistiques de visite (GoatCounter).**
Pour savoir quelles pages et quels liens intéressent les visiteurs, le site utilise
[GoatCounter](https://www.goatcounter.com), un outil de statistiques **sans cookie et sans
identifiant persistant**. Sont enregistrés : la page consultée, les sections affichées, les clics
sur les liens de contact, le site de provenance, le type de navigateur et de système, la taille de
l'écran et le pays approximatif. Selon la documentation de GoatCounter, l'adresse IP sert
uniquement à éviter de compter deux fois une même visite et n'est pas conservée.
Finalité : améliorer le contenu du site (intérêt légitime).

**Hébergement (GitHub Pages).**
Comme tout hébergeur, GitHub enregistre l'adresse IP des visiteurs dans ses journaux techniques
pour la sécurité et le bon fonctionnement du service. Voir la
[déclaration de confidentialité de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

**Échanges par e-mail.**
Si vous m'écrivez, j'utilise votre adresse et votre message uniquement pour vous répondre.
Ils sont conservés le temps de l'échange, puis supprimés à votre demande.

**Préférence de langue.**
Le choix FR / EN est mémorisé dans votre navigateur (stockage local). Il n'est jamais envoyé ;
vous pouvez l'effacer en vidant les données du site.

**Polices de caractères.**
Elles sont hébergées avec le site : aucune requête n'est envoyée à Google ou à un autre tiers.

## Vos droits

Vous pouvez demander l'accès à vos données, leur rectification ou leur effacement, ou vous opposer
à leur traitement, en écrivant à [{{ id.email }}](mailto:{{ id.email }}).

Vous pouvez aussi adresser une réclamation à l'autorité de protection des données compétente :
au Niger, la **Haute Autorité de Protection des Données à caractère Personnel (HAPDP)** ;
si vous résidez dans l'Union européenne, l'autorité de votre pays (en France, la **CNIL**).

## Cadre juridique

Loi nigérienne n° 2017-28 du 3 mai 2017 relative à la protection des données à caractère
personnel et, pour les visiteurs résidant dans l'Union européenne, le Règlement général sur la
protection des données (RGPD).
